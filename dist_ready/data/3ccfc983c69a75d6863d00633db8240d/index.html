At the event, you will hear presentations that set out: The context in which this Project I being taken forward: Address Mali's vulnerability to climate change and water security challenges. The projects goals: Improve access to drinking water in Mali, support economic development, and reduce fragility and conflict. Optimize project structuring before launching the procurement process. Project Details in brief San Center:14 boreholes, new treatment plant, storage facilities, and distribution network expansion. Mopti/Sévaré Center:12 boreholes, rehabilitation of treatment plant, new pumping stations, storage facilities, and distribution network expansion. The event will take place at 10.00am Mali time.
