2021年世界銀行グループ・国際通貨基金春季会合において、参加者の皆さんにこのようにお話しする機会をいただき心より感謝いたします。本日は、教皇庁人間開発のための部署の長官を務めるピーター・タークソン枢機卿に託したこの手紙で、私の思いと考えを皆さんにお伝えしたいと思います。 2020年、私たちが暮らす世界は、新型コロナウイルス感染症（COVID-19）により、社会経済、生態系、そして政治の、相互に結びついた深刻な危機に直面しました。私は、春季会合で皆さんが協議を重ねることで、新たな「回復」のモデルが生まれることを願ってやみません。これは、実体経済を支える新たな、そしてより包摂的で持続可能な解決策を生み出し、世界の人々と共同体の願いが叶うよう、そして普遍的な共通善が達成されるように支える回復モデルであり、世界の人口のごく僅かな人々が世界の富の半分を占めるような、不平等で持続不可能な経済・社会への回帰であってはなりません。 「すべての男性と女性は生まれながらにして平等である」。私たちがそう固く信じる一方で、多くの兄弟姉妹、とくに社会の片隅に追いやられている人々が、金融の世界から事実上排除されています。しかし、COVID-19のパンデミックにより、「だれも一人では救われない」ことに改めて気付かされることとなりました。私たちがこの状況から、より人間的で連帯したより良い世界として抜けだすためには、社会、政治、及び経済への参加の創造的な新しい形を作りださなければなりません。貧しい人々の声に耳を傾け、新しい共通の未来に彼らを組み込むことを誓わなければなりません（フラテッリ・トゥッティ、169）。金融と経済の専門家である皆さんは、人々のつながりから生まれる信頼こそが、金融分野も含めあらゆる関係の礎であることはよくご存知でしょう。全ての声が反映され全ての人が栄えることができる「出会いの文化」を発展させて初めて、こうした関係を築き上げることができるのです。これは、人々との接点を持ち、橋を作り、包摂的な長期的プロジェクトを描く文化です。（同上、216） 多くの国が、それぞれの回復プランの強化に取り組んでいます。しかし、グローバル・ガバナンスの新たな制度を生み出す、あるいは既存の制度を再建し、極めて重要な全人的な発展を促すための、国際関係の新たなネットワークの構築を支える、グローバルな計画の策定という喫緊のニーズが残されたままとなっています。これは、貧しく発展途上にある国々が、意思決定プロセスの重要な一翼を担うこと、そして、こうした国々の国際市場へのアクセスを促進することが必要であることを意味しています。また、COVID－19のパンデミックにより、最貧国が抱える債務負担が一段と拡大しました。世界的な連帯の精神を踏まえれば、少なくともこの債務の大幅な削減が必要です。現在の状況において、多くの国々や共同体が抱える債務の負担を軽減することは、極めて人道的であり、人々の発展に加え、ワクチンや、健康、教育、そして仕事を得る助けとなります。 さらに、もうひとつの債務も見逃すことはできません。グローバル・ノースとグローバル・サウスの間に存在する「生態系の債務」です。私たちは皆、実は自然、そして人間がもたらす生態系の悪化と生物多様性の損失の影響を受けている人々や国々に対し、債務を抱えていると言えます。この点において、私は、優れた創造力を持つ金融業界が、この生態系の債務を計算する機動的なメカニズムを開発する能力があることを証明することができると確信しています。このメカニズムにより、先進国が、非再生可能エネルギーの消費を大幅に抑制し、貧しい国々による、持続可能な開発のための政策やプログラムの制定を支援するだけなく、こうした目的に必要なイノベーションのコストをカバーすることで、この債務を支払うことができます。（ラウダート・シ、51－52） あらゆる経済活動の真の目的そして目標である、普遍的な共通善への深い理解が、公正かつ平等な発展の要です。公的な資金が公益から決して切り離されることなく、また、金融市場が、共通善のための真の働きをすることができるよう、法と規制で支えることが重要でしょう。このように、経済、金融、そして社会の連帯への誓いは、寛大な行動を散発的に取る以上のことを意味します。「それは、共同体の視点から考え行動することを意味する。それは、すべての人の生活が、少数の人々による富の占有より優先することを意味する。それはまた、貧困、不平等、仕事、土地、住居の不足、社会的権利や労働の権利の否定の構造的な原因と闘うことを意味する……。連帯とは、その最も深い意味で理解するなら、歴史を作る手法である」。（フラテッリ・トゥッティ、116） 私たちは、市場、特に金融市場を支配するのは、市場ではないことを認めなければなりません。市場が共通善のために機能するよう法律と規制で支える必要があり、また、金融が、単なる投機や自己金融のためはなく、世界が健康上の緊急事態にある今、何よりも必要とされている社会的目標のために機能するようにしなければなりません。 この点において、特に「vaccine solidarity（ワクチンでの連帯）」への資金拠出が必要だと言えるでしょう。市場の法則が、愛の法則、そしてすべての人々の健康に優先するようなことがあってはならないのです。私は本日、政府、ビジネス界、そして国際機関のリーダーである皆さんが、力をあわせ、最も脆弱で助けを必要としている人々をはじめ、全ての人々がワクチンを接種できるよう取り組むことが重要であると、改めて申し上げたいと思います。（ウルビ・エト・オルビ・メッセージ、2020年クリスマス） 今日のこのような情勢において、皆さんが参加される公式な協議とさまざまな人との出会いが、より包摂的で持続可能な未来への賢明な解決策を識別する上で重要な、大きな実りとなることでしょう。金融が共通善を支え、脆弱な、そして取り残された人々が中心となった、私たちの共通の家である地球を大切にする未来を築きましょう。 春季会合が実りあるものになるようお祈りするとともに、ここに集う全ての人々に、神のご加護により、英知と理解、導きと力、そして平和がもたらされますよう祈念しております。 バチカンにて 2021年4月4日 Api Api Welcome Feedback Survey Feedback Survey -->
