Menu Data Metrics Open Government Contact User Guide User Guide Back to updates Introducing New Rural Housing Data from USDA By Data.gov admins · July 26, 2016 For the first time, USDA’s Rural Housing Service is publicly releasing data across every program area in which the agency provides loans, guarantees, and grants—multifamily housing, single-family housing, and community facilities. This set of data will bring stakeholders and the public unprecedented insights into rural housing program delivery, impacts, challenges, and opportunities across the country. It will be updated regularly, so check back frequently for the latest release. Click here for the data. Mapping applications like PolicyMap are incorporating USDA’s rural housing data and overlaying them with other indicators.
